# 보고서 스크롤 점 네비게이션 설계

## 목표

긴 EM4043 보고서에서 현재 위치를 빠르게 파악할 수 있도록 우측에 섹션 점 네비게이션을 제공한다.

## 동작

- 페이지 최상단에서는 네비게이션을 숨긴다.
- 아래로 스크롤하면 `opacity`와 `translateY` 전환으로 자연스럽게 표시한다.
- `IntersectionObserver`로 현재 섹션을 감지하고 해당 점과 요약 라벨을 활성화한다.
- 점을 클릭하면 해당 섹션으로 부드럽게 이동한다.
- 최상단으로 돌아오면 네비게이션을 다시 숨긴다.
- 기존 우측 하단 TOP 버튼과 겹치지 않도록 우측 중앙에 배치한다.
- 모바일 화면에서는 네비게이션을 숨겨 본문 폭을 보존한다.

## 대상 섹션

`overview`, `architecture`, `business-scenarios`, `scenarios`, `management`, `comparison`, `progress`, `challenges`, `future`.

## 검증 기준

- 스크롤 전 네비게이션이 보이지 않는다.
- 아래로 스크롤할 때 네비게이션이 부드럽게 나타난다.
- 현재 섹션 변경에 따라 활성 점이 바뀐다.
- 점 클릭 시 해당 섹션으로 이동한다.
- 최상단 복귀 시 네비게이션이 숨겨진다.
