# 登录与权限测试人工输入规则

## 必须人工完成

- ESM 登录账号和密码。
- Jira OAuth 用户名、密码和授权确认。
- Jira OAuth Token、ESM Cookie、ESM MCP Token。
- 管理员权限确认、项目权限变更和账号解锁。
- 任何会改变 Jira、Zabbix 或 ESM 数据的确认按钮。

## 可以自动检查

- 页面是否跳转到正确回调地址。
- HTTP 状态码和脱敏响应结构。
- JWT 是否存在、有效期字段是否符合预期，不读取完整 Token。
- Redis key、字段名称和 TTL。
- MySQL 测试记录的状态和关联 ID。
- SSE 事件顺序、结束事件和非敏感结果。

## 禁止事项

- 不自动尝试密码。
- 不重复提交登录表单。
- 不在命令行、日志、截图或 Markdown 中保存完整密码、Cookie 或 Token。
- 账号被锁定后不继续重试，必须由管理员解锁后重新开始测试。
