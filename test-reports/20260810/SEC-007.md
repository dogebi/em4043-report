# SEC-007 审计日志不含敏感信息

| 项目 | 内容 |
| --- | --- |
| 当前状态 | PARTIAL |
| 执行方式 | 代码审查 |
| 需求依据 | 表 30，审计日志不含密码、API Key、完整 Token |
| 实际结果 | 管理端 `OperationLog::filterData()` 会遮蔽字段名包含 `password` 和 `token` 的值。未覆盖 `api_key/secret` 字段；Jira webhook controller 会把全部 headers 和 params 写入日志，存在敏感头落库风险。 |
| 主要证据 | `OperationLog::filterData()`、`WebhookNttJiraController::index()` |
