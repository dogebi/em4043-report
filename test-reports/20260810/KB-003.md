# KB-003 单文档同步失败不影响整体

| 项目 | 内容 |
| --- | --- |
| 当前状态 | PARTIAL |
| 执行方式 | 代码审查 |
| 需求依据 | 表 25，单文档解析失败自动重试 3 次，失败日志可查，其他文档正常同步 |
| 实际结果 | `FileReleaseCommand` 逐个处理 Redis 队列文件，单个异常会标记 `PARSE_ERROR` 并继续后续文件；`FileSyncStatusCommand` 会同步 `RUNNING/DONE/FAIL` 到本地状态并写 `parse_log`。未发现固定 3 次自动重试计数和管理员失败记录页面的验证。 |
| 主要证据 | `FileReleaseCommand::handle()`、`FileSyncStatusCommand::handleItem()` |
| 缺口 | 3 次重试计数、管理员失败记录 live 验证缺失 |
