# KB-011 项目级SOP蒸馏（≥5工单）

| 项目 | 内容 |
| --- | --- |
| 当前状态 | PARTIAL |
| 执行方式 | 代码审查 |
| 需求依据 | 表 27，≥5 个 Closed Incident 按项目+Agent 聚合，质量门禁后生成 project SOP，直接发布并回传 Jira |
| 实际结果 | distill worker 可消费 `stream:distill_tasks`，筛选 closed 工单，少于 5 个会失败，LLM 生成 SOP 并质量评分，保存 draft SOP。缺口较大：聚合未按项目过滤，`_get_agent_project_id()` 固定返回 1；没有时长 >5min 门禁；保存状态是 `draft` 而非直接发布；未发现 Jira 回传。 |
| 主要证据 | `distill_tasks.run_distillation()`、`DataAggregator.aggregate()`、`DistillationPipeline.run()`、`save_sop_draft()` |
| 缺口 | 项目+Agent 分组、时长门禁、project scope 发布、Jira 回传缺失 |
