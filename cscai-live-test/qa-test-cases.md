# 测试用例 Q/A 格式

**### Q：为单个工单生成客户报告**

**### A：报告对应当前工单，准确概述问题、影响、处理过程和结果；语言适合客户阅读。--正确**

- 用例编号：TC-01
- 功能：Jira工单客户报告
- 操作与测试数据：选择一个包含问题描述、处理过程、解决方案和状态的 Jira 工单，生成报告

--------------

**### Q：工单包含内部备注或敏感信息**

**### A：客户报告不泄露内部备注、凭据、内部链接等不应对客展示的信息。--正确**

- 用例编号：TC-02
- 功能：Jira工单客户报告
- 操作与测试数据：在工单中加入内部备注、内部链接或敏感字段，再生成客户报告

--------------

**### Q：工单信息不完整**

**### A：报告明确标注信息缺失或尚未确认，不编造根因和处理结果。--正确**

- 用例编号：TC-03
- 功能：Jira工单客户报告
- 操作与测试数据：使用缺少根因或解决方案的工单生成报告

--------------

**### Q：翻译常见工单内容**

**### A：译文保留原意、故障术语和语气；无明显漏译或错译。--正确**

- 用例编号：TC-04
- 功能：翻译功能
- 操作与测试数据：输入一段中文故障描述，翻译为选择的目标语言

--------------

**### Q：文本含专有名词和技术内容**

**### A：编号、命令、日志及专有名词保持准确，不被误译或改写。--正确**

- 用例编号：TC-05
- 功能：翻译功能
- 操作与测试数据：输入包含 Jira 编号、资产编号、命令、日志和产品名的文本

--------------

**### Q：空文本或翻译失败**

**### A：空文本得到合理提示；服务失败时提示失败原因或可重试，不返回伪造译文。--正确**

- 用例编号：TC-06
- 功能：翻译功能
- 操作与测试数据：输入空文本，或模拟翻译服务不可用

--------------

**### Q：汇总当前所有未关闭工单**

**### A：统计范围包含当前所有未关闭工单；数量及分类与 Jira 数据一致，并标明统计时间。--正确**

- 用例编号：TC-07
- 功能：Leader统计
- 操作与测试数据：准备多个未关闭工单，涵盖不同优先级、负责人和状态，生成汇总

--------------

**### Q：排除已关闭工单**

**### A：已关闭工单不计入未关闭数量和摘要；统计口径清晰。--正确**

- 用例编号：TC-08
- 功能：Leader统计
- 操作与测试数据：在数据集中加入已关闭工单，再生成未关闭工单总结

--------------

**### Q：当前没有未关闭工单**

**### A：显示无未关闭工单或空结果说明；不生成虚假的事项和风险。--正确**

- 用例编号：TC-09
- 功能：Leader统计
- 操作与测试数据：将所有工单设为关闭后生成总结

--------------

**### Q：生成单项目月报**

**### A：报告项目、月份范围正确；工单数量及状态、优先级等统计与源数据一致。--正确**

- 用例编号：TC-10
- 功能：SM月度项目统计
- 操作与测试数据：选择一个项目和月份，准备该月工单数据，生成统计报告

--------------

**### Q：月份边界和无数据月份**

**### A：工单按约定的日期字段归属月份；无数据时明确显示，不出现跨月重复或虚构统计。--正确**

- 用例编号：TC-11
- 功能：SM月度项目统计
- 操作与测试数据：使用跨月工单，并选择没有工单的月份

--------------

**### Q：生成资产统计**

**### A：资产总数及分类统计与资产数据一致；资产范围和统计时间明确。--正确**

- 用例编号：TC-12
- 功能：SM资产统计
- 操作与测试数据：选择资产范围，准备不同类型、状态或归属的资产数据

--------------

**### Q：生成常规交接班报告**

**### A：报告包含需交接事项、当前进展、责任人、下一步行动和风险；信息便于接班人继续处理。--正确**

- 用例编号：TC-13
- 功能：交接班报告
- 操作与测试数据：准备未关闭工单、负责人、处理进度、待办和风险信息，生成交接班报告

--------------

**### Q：验证最终分析价值**

**### A：最终分析能指出有数据依据的共性、风险或待验证方向，并区分已确认事实与推测。--正确**

- 用例编号：TC-14
- 功能：交接班报告
- 操作与测试数据：准备存在重复故障、关联变更或共性现象的工单，再生成交接班报告

--------------

**### Q：为已解决工单生成结单报告**

**### A：报告包含问题概述、影响、根因（如已确认）、处理措施、验证结果和结单状态；内容与工单一致。--正确**

- 用例编号：TC-15
- 功能：结单报告
- 操作与测试数据：使用已关闭或已解决的工单生成报告

--------------

**### Q：为未关闭工单尝试生成结单报告**

**### A：系统提示工单尚未满足结单条件，或明确标记为草稿/未结案；不得将工单描述为已完成。--正确**

- 用例编号：TC-16
- 功能：结单报告
- 操作与测试数据：使用仍在处理中或待客户确认的工单生成报告

--------------

**### Q：查询项目联系人**

**### A：返回该项目所有联系人及其角色、职责和联系方式；信息来源明确，不编造不存在的人员。--正确**

- 用例编号：TC-17
- 功能：知识库查询
- 操作与测试数据：选择一个已录入联系人信息的项目，提问"这个项目的联系人有哪些？"

--------------

**### Q：查询项目服务的据点**

**### A：返回该项目服务的所有据点名称及相关信息（如地址、服务范围）；列表完整且与知识库数据一致。--正确**

- 用例编号：TC-18
- 功能：知识库查询
- 操作与测试数据：选择一个已录入据点信息的项目，提问"这个项目服务了哪些据点？"

--------------


**### Q：查询当前工单的通知模板并列出通知对象**

**### A：根据当前工单类型和场景匹配到正确的通知模板；列出所有应通知的对象及其邮箱，信息来源可追溯，不遗漏、不捏造。--正确**

- 用例编号：TC-19
- 功能：任务会话与知识库联动
- 操作与测试数据：选择一个已关联项目和通知模板的工单，提问"当前工单应该使用什么通知模板，并列出所有通知对象及他们的邮箱"
--------------
